## Prototype Scope

The prototype compares internal ledger, bank, and payment-gateway
records; identifies reconciliation breaks; retrieves similar cases; and
suggests possible next actions for human review.

## Important Limitations

-   The current prototype uses deterministic rules, hand-weighted
    similarity, and case retrieval. It is not a trained machine-learning
    model or an LLM/GenAI system.
-   Recommendations require human review. The prototype does not
    automatically resolve breaks.
-   The demonstration uses synthetic, fictional data only. No real
    banking or customer data is included.
-   The prototype is not production-ready. Authentication, hardened API
    access, and tamper-proof audit logging are among the controls that
    would need to be addressed before production use.
